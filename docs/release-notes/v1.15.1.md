## Fixed: "Installation failed ... Permission denied" when updating
Installing over an existing Sentinel could fail with a `[Errno 13] Permission denied` error on `Sentinel.exe`. That happened when the old Sentinel couldn't be closed: a copy running as administrator, or another antivirus (like Norton) holding the file open.

Setup now:
- **Asks to close an administrator copy of Sentinel** with the Windows admin prompt, instead of failing.
- **Moves a locked file out of the way** and puts the new one in its place, so a file that's still in use no longer stops the install. The leftover is cleaned up next time.
- **Explains what to do** if a file still can't be replaced (restart and run Setup again, or check whether your other antivirus blocked Sentinel), instead of showing a raw error. In all five languages.

## Upgrading
If you're on 1.13.0 or later, this installs automatically in the background. Otherwise, open the **Updates** tab and click **Update now**, or run **SentinelSetup.exe** below over your existing install. If the 1.15.0 installer failed for you, just run this one.

The installer isn't code-signed, so Windows SmartScreen will warn you. Click **More info → Run anyway**.
